# FieldIQ data

FieldIQ combines independent, timestamped datasets rather than treating one file as the source of truth.

## Sources

- `games.parquet` — nflverse schedules, results, rest, venue, and historical weather
- `team_weekly.parquet` — nflverse weekly team statistics and EPA
- `player_weekly.parquet` — nflverse weekly player statistics
- `rosters.parquet` — nflverse current rosters
- `injuries.parquet` — nflverse injury/practice reports
- `weather_daily.parquet` — official NOAA/National Weather Service forecasts

The large Parquet files are generated by the daily workflow and uploaded as a GitHub Actions artifact. They are ignored by Git to avoid growing the repository every day. Small application outputs in `processed/` are committed so Vercel can serve them.

Every prediction is produced from information available before kickoff. The generated feature table has one row per game, and rolling statistics use prior games only.
